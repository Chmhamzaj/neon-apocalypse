# Nitro Street Rush — Completion Roadmap

## Implemented foundation
- Blender 5.2 procedural asset lab
- Hero supercar and driver geometry
- Unity 6 URP/C# production scaffold
- Unreal 5.8/C++ vehicle scaffold
- Godot 4.5 Android fallback
- Python asset manifest/automation
- Mobile touch input
- Nitro HUD
- Race progress
- Dynamic traffic spawning
- Adaptive Android quality tiers
- Persistent save data
- Green signed Android smoke build

## Next production passes
1. Replace blockout geometry with authored hero/traffic vehicle meshes and PBR texture sets.
2. Build modular city/road streaming with elevation, ramps, bridges and intersections.
3. Add wheel/suspension animation and collision damage.
4. Add spline-based AI racing lines, overtaking and rubber-banding.
5. Add drift model, traction loss, jump airtime and landing stabilization.
6. Add camera modes: chase, near-chase, cockpit and cinematic.
7. Add audio: engine RPM layers, tire scrub, wind, impacts, nitro.
8. Add race menu, garage, car selection, upgrades and progression.
9. Add quality presets and GPU/thermal safeguards for Android.
10. Profile on representative Android hardware and optimize draw calls, memory, texture streaming and physics.

The game remains an original IP rather than a clone of any commercial racing game.
