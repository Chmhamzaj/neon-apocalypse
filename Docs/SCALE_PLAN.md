# Scale Plan

The project is designed to grow in this order:

Build 0.3 — data-driven 12-region campaign + story systems.
Build 0.4 — Region 01 environment, traversal, inventory, crafting, skill tree and cinematics.
Build 0.5 — remaining regions and additive scene streaming.
Build 0.6 — high-fidelity character/animation/VFX/audio production pass.
Build 0.7 — optimization, device tiers, QA, save migration, accessibility and localization.
Build 1.0 — release candidate, AAB signing, Play Console assets and staged testing.
