# NEON APOCALYPSE — Street Sovereign 3D Android

Unity 6 Android 3D project. The Street Sovereign branch is being validated through automated Android APK export, runtime smoke testing, and APK signature/installability checks before an APK is released.

Build target: Android APK
Engine: Unity 6.0.43f1
Validation: CI build + runtime smoke test + apksigner verification

The APK is not released to the user until the CI validation passes.
