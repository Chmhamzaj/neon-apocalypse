# Presentation Layer

## Race flow
- Main menu
- Garage
- Countdown
- Live HUD
- Pause
- Finish/results

## Live HUD
- Speed in KM/H
- Nitro capacity
- Race percentage
- Damage state
- Race-state indicator

## Cameras
- Chase camera
- Cockpit camera
- Cinematic camera

## Progression
- Persistent credits
- Best race time
- Selected car
- Nitro capacity upgrades

## Production visual integration
The scene hierarchy should keep gameplay components separate from visual meshes so imported HD assets can be replaced without changing race logic.
