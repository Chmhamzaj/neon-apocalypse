# Nitro Street Rush — HD Racing Stack

Primary target: Unity 6 + URP + C# for the production Android build.

Asset pipeline:
Blender 5.2 LTS automation -> GLB/FBX -> Unity 6 import -> URP materials -> mobile LODs -> Android.

Secondary engine targets:
- Unreal Engine 5.8: C++ prototype/graphics validation.
- Godot 4.5/4.6: lightweight/mobile fallback and current playable prototype.

Required production goals:
- physically-based car materials
- multi-level LODs
- real-time shadows and reflection strategy
- articulated suspension/wheels
- proper 3D traffic AI
- spline/path based road network
- dynamic chase, cockpit and cinematic cameras
- touch steering + tilt steering
- nitro, drifting, jumps and collision response
- scalable Android quality tiers

This is an original street-racing game; it does not copy proprietary cars, tracks, UI, characters or branding from commercial games.
